# Eric White for Maine House District 16

Static campaign starter site for Eric M. White, candidate for Maine House District 16 in the 2026 general election.

Live site: https://will292929.github.io/eric-white-maine-house-16/

## Publishing

This repository is designed for GitHub Pages. The site uses plain HTML, CSS, and JavaScript with no build step.

## Forms

Website submissions post to a private Google Form owned by the campaign's contract account. The recipient email address is intentionally absent from the repository and public pages. Google Form identifiers are public routing identifiers; they do not grant access to responses.

## Content status

Biography, policy positions, campaign contact details, and the paid-for statement remain clearly marked for campaign review. Replace those placeholders only with campaign-approved facts.
